# Deterministic document export

Covers: `document.export`, `exportDocument`, `printNormalizedDocument`.

1. Export `normalized.txt`, `document.json`, `images.json`, `processing-report.json`, and every available figure image. Use the canonical document for text. Preserve complete block content without sentence splitting, trimming, table flattening, or equation conversion.
2. Emit stable page and block/source labels, including blank source pages. Print a cross-page joined block once, identify every contributing source location, and point later pages to its existing label. Keep caption blocks labeled as author captions. Figure records reference those labels when their unchanged caption is already present; otherwise retain the original caption separately. Label generated descriptions `AI-written`; disclose unavailable assets/descriptions.
3. Use compact `JSON.stringify` bytes for the three JSON documents, matching OutputStore's checked serialization. Hash the exact returned UTF-8/image bytes through Effect Crypto. Image bytes must match the canonical image path/type/count/hash; reject missing, extra, duplicate, or conflicting files. No image transformations or network calls occur during export. Preserve rendered-region provenance in document.json and images.json and identify it in normalized.txt. Historical assets without provenance remain unspecified.
4. Return the publication objects plus files with their actual artifact entries. Add the export check only to the successfully returned report. The manager stores every file privately, validates persisted receipts and byte identities, and atomically publishes the run. This module performs no storage or run mutation.
5. Offline tests cover legacy content omissions, cross-page joins, heading demotion, blank-page accounting, missing figure descriptions/assets, exact bytes/hashes, same-run replay, failed receipts, and honest unavailable counts. Manager Chrome/download checks establish the integrated delivery separately.
