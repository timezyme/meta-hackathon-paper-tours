# Document reader

1. Render only the owner-authorized current output revision. Decode canonical document, processing report, and rating with shared product schemas and reject mismatched document/revision/run identities. Keep queued, failed, interrupted, loading, expired, unauthorized, and unreadable output states explicit. There is no fixture fallback in application code. Preserve typed HTTP status in both document and output read errors: 410 offers return/re-upload guidance without retry; ambiguous 404 and temporary failures retain explicit retry.
2. The goal-first workspace offers a saved overview, one walkthrough step or claim per screen, completion and return to choices. It retains the Live Page reading surface, page/section sidebar, prominent Copy and ZIP actions, and Downloads & details in a native modal dialog at every width. Historical output without a guide explains its absence and retains the full reader/downloads. Preserve the brand, serif document body, dark default/light theme, complete report, rating and deletion controls. Under 900px the source sidebar becomes a Pages modal. The Original/Clean copy switch preserves the selected source page; preview uses an authenticated image of that single original page without inference. The original remains downloadable when preview rendering is unavailable. Use actual report issues and warn that AI output may be wrong; do not carry sample-specific edit counts, explanations or source boxes into real documents.
3. Page count and content come from canonical data. `?p=` uses actual source page numbers and clamps to first/last bounds. Explicit source, footer, continuation, or issue navigation closes any drawer, then scrolls to and focuses the rendered page article through the Effect DOM boundary. Consume that navigation request once; ratings and status polls never move reading focus. Back/Forward and refresh recover the page using native history scroll restoration. A joined block is rendered once on its first source page; later pages link to that original location. References, notes, tables, captions, images, and unavailable descriptions remain visible.
4. Render text-format blocks literally with preserved newlines/whitespace and wrapping; never infer Markdown or code from their content. The one exception is a bounded `**bold**` span (opened at the start, after whitespace or `(`; closed before the end, whitespace or punctuation; one line; no edge whitespace), which the extractor writes into text blocks: show it bold in the reader and without markers in heading labels and source evidence. Every other `*`, `_` and `#` stays literal. Canonical heading kind/level controls heading markup and removes its normalized heading prefix. Other declared formats retain Markdown/GFM, sanitized HTML tables and intentional math through public renderer packages. Sanitize before trusted KaTeX rendering and disable trust features. Uploaded HTML cannot supply scripts, styles, active controls, unsafe links, or image loads. Only canonical figures use the owner-authorized image route. Literal newlines and HTML breaks inside table cells remain visible. Wide tables/equations scroll inside the reader; they cannot widen the viewport. Prose and list children have a 52ch reading measure while figures, tables and equations retain the available width.
5. `client/outputs.ts` owns scoped Effect HTTP with a 30-second deadline and no automatic retries. Unmount cancels reads and mutations. Copy fetches the complete UTF-8 normalized-text endpoint; clipboard conversion is the explicit Promise boundary. Bound the clipboard wait to ten seconds independently of the HTTP deadline. Rejection or timeout unlocks Copy and offers the text-download fallback without claiming success; timeout says "Copying took too long. Download the text file instead." Ignore late completion in the UI after timeout or unmount. The browser's clipboard operation itself cannot be aborted. Rating updates apply only after confirmed responses and prevent concurrent submission. ZIP, text, original PDF, current document JSON, and report downloads use the frozen product routes. Keep JSON and report links inside the collapsed Processing report.
6. Display report counts directly, retaining unavailable metrics as unavailable. Summarize saved Muse reviews in plain words: a corrected review says the check caught and fixed a problem; a fallback says Muse checked it and kept the original text (or headings, or published without a figure description or guide). Issues backed by a recorded fallback lead with that sentence and link to compare the page. Disclose actual receipt model, effort, prompt name/version, attempt state, delivery, and reported usage/cost. Public prompt templates are selected only by an approved exact version mapping. Never expose raw provider replies, hidden reasoning, credentials, or fabricated quality scores. The download summary states the unresolved issue count and offers Review issue(s), which opens and focuses that panel instance’s native report summary. Rating buttons retain their visible names.
7. Verify a labeled multi-page fixture with joined prose, math, wide tables, references, notes, unavailable figures, and injection strings in installed Chrome at 320, 390, 1024, and desktop widths in both themes. Exercise dialogs, history, bounds, copy, ratings, disclosures, output errors, and no remote image requests. Fixture verification is not evidence of live processing or visual accuracy.
8. Query-only page navigation retains the authenticated document session and loaded output; pathname changes and session refresh events still revalidate. Sign-in retains its complete return-path query behavior. Delete is enabled only for terminal documents, requires a native modal confirmation explaining original/output removal, sends one owner-authorized DELETE, and navigates home only after 204. Pending deletion locks the confirmation; failures remain explicit without automatic mutation retry or a false success. The server remains authoritative for active-run conflicts and tombstoned/expired/foreign documents.

9. Offer processing retry only when the current failed/interrupted run projects retryable=true. Use a native confirmation; provider-unknown-completion requires explicit acknowledgment that work and cost may repeat. Save the owner/document/previous-run/key/exact request in sessionStorage before POST. Preserve that submission after uncertain responses, navigation and reload, and reuse it only on another explicit user action. Never automatically retry POST or silently generate a replacement key. Reject malformed or mismatched saved submissions. Only an identity-matching 202 starts status refresh; retain existing published output while the new run progresses. The backend revalidates eligibility, reuse, budget and admission.

This port calls only owner-authorized document contracts. It adds no direct model execution or publication. Manager-owned backend and final real-output browser checks remain separate from the fixture UI checks.

10. Guide evidence resolves quotations only against immutable source blocks. Display the exact quotation highlighted within its actual stored source block, with other source blocks from that page and an Original switch. Source locations supply page choices; page-only locations never acquire invented pixel boxes. Guide text renders as literal text. Read boundaries reject invalid citations or a guide without its matching accepted completed receipt. Bounded URL state restores modes, steps, claims, source selection and view on refresh/history; explicit guide turns focus the new heading without status polls stealing focus. Arrow shortcuts apply only outside interactive controls and open dialogs.
