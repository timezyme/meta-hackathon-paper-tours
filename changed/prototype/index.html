Input

Prompt draft
page-repair / draft-v1
View prompt
Compare the extracted text with the supplied page image.

Restore reading order. Rejoin paragraphs split by columns or page breaks. Correct extraction errors in symbols, equations, and formulas using the page as the source of truth.

Preserve the author's meaning and qualifications. Do not solve, simplify, or invent content. Log unresolved characters rather than guessing.

Return the corrected text and a list of changes with source locations.

Model ID
muse-spark-1.3
Reasoning setting
Medium
Input
Corrected document blocks
Prompt draft
heading-structure / draft-v1
View prompt
Identify the title, sections, and subsections in the document blocks.

Restore heading levels from the document's visual and structural evidence. Preserve the original wording, block IDs, and reading order. Do not turn captions or emphasized sentences into headings.

Return a heading map. Log unresolved heading levels.
4Describe figuresMuse Spark 1.3 · High
Model ID
muse-spark-1.3
Reasoning setting
High
Input
2 extracted images + captions
Prompt draft
figure-description / draft-v1
View prompt
Describe what is visible in each figure using its image and caption.

For charts, identify axes, units, legends, trends, and visible comparisons. For diagrams, identify components and relationships. Distinguish visible observations from interpretation. Do not invent values that cannot be read.

Return a description linked to the figure's source block. Label it as AI-written.
